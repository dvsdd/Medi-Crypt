# MediCrypt: Hybrid framework for securing medical images using ResNet50 assisted Steganography and cryptographic encryption

> Authors: Keshava and team

## About

Hybrid security framework with layers of encryption and steganography that is assisted by ResNet50 to store medical images.
Image encryption using AES(128 bit), and steganography using DCT Discrete Cosine Transform.

#### Input
Medical Image like MRI, CT scan,etc.
Cover Image in .tiff format

##### Output
Multiple cover images which contain the Medical Images but invisible to naked eyes
